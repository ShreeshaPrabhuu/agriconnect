# AgriConnect 🌱

> **Empowering marginal farmers with on-demand rural crews and direct-to-buyer market access.**

**Hackathon:** DevHost 2026  
**Theme 1:** AgriTech, Rural Innovation & Blue Economy[cite: 1]  
**Problem Statement (PS 1.2):** Direct Market-Access Platform for Marginal Farmers[cite: 1]  

---

## ⚠️ The Problem
Marginal farmers in Coastal Karnataka (Dakshina Kannada and Udupi) face two critical friction points[cite: 1]:
1. **Margin Loss:** They lose up to 30% of their profits to middlemen due to opaque local pricing and lack of direct buyer access[cite: 1].
2. **Labor Shortages:** The rural agricultural workforce is completely unorganized and offline, causing 5-10 day delays in finding reliable harvesting crews during peak seasons.

## 💡 Our Solution
AgriConnect is a unified, voice-first ecosystem built specifically for rural India. It merges **Hyper-Local Labor Discovery** with a **Direct-to-Buyer Crop Marketplace**[cite: 1]. Farmers can book verified local worker crews (*Mukkadams*) via GPS, pay them via a digital Khata, and immediately sell their harvested produce to wholesale buyers using transparent, real-time APMC Mandi prices[cite: 1].

## ✨ Key Features

*   📍 **GPS Crew & Labor Finder:** Radius-based (3km - 30km) scanner to locate and book individual specialists or entire 4-10 member group crews.
*   🌾 **Direct Market Access (PS 1.2):** Live comparisons of local Mandi rates vs. Direct Buyer prices for crops like Arecanut, Pepper, and Coconut. Allows zero-commission direct listings[cite: 1].
*   ⭐ **Smart Auto-Ranking Engine:** Dynamically sorts workers from top to bottom based on a weighted formula (50% Rating, 30% Proximity, 20% Reliability). Includes a "Newcomer Boost" for unrated profiles.
*   🗣️ **Zero-Barrier Accessibility:** Multilingual UI (Kannada, Hindi, English), Voice-Search simulation, and 1-tap Emoji ratings (⏰, 💪) to overcome rural literacy barriers.
*   📒 **Hybrid Wage Khata:** A built-in digital ledger to track on-field cash handovers, advances, and UPI settlements.
*   🔄 **365-Day Utility:** Toggles between seasonal agricultural work and off-season rural trades (pump mechanics, masonry) to ensure year-round employment.

## 🛠️ Technology Stack

This project is built as a fast, zero-dependency static prototype for seamless demonstration:
*   **Frontend:** HTML5, Vanilla JavaScript (ES6+)
*   **Styling:** Tailwind CSS (via CDN)
*   **Icons:** FontAwesome
*   **Data Management:** Local JS Arrays (simulating a backend database)

## 🚀 How to Run Locally

Since this is a static web application, no complex build tools or servers are required.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/ShreeshaPrabhuu/agriconnect.git](https://github.com/ShreeshaPrabhuu/agriconnect.git)
    ```
2.  **Navigate to the project folder:**
    ```bash
    cd agriconnect
    ```
3.  **Run the application:**
    Simply open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari).
    *(Alternatively, use an extension like VS Code Live Server for hot reloading).*
